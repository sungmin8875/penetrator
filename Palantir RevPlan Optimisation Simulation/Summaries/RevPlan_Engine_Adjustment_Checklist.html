2 How the engine works today현재 엔진 동작 방식

net_production_demand (demand − shipped/transit/onhand, roll forward)(수요 − 출하/이동/재고, 이월)
  → step_priority_assignment (emergency → delivery date → remaining steps)(긴급 → 납기 → 잔여단계)
  → allocate_month_by_month:
     FOR month월 → FOR model by priority모델(우선순위):
       total = base + carryover
       Phase 1: allocate WIP (closest-to-done)WIP 할당(완료 임박)
       Phase 2: create virtual lots × 1.1 buffer가상 로트 생성 ×1.1 버퍼
       schedule each step → least-loaded equipment (cap = sheets/day)단계별 스케줄 → 최저부하 설비(용량=시트/일)
       carryover = total − units_allocated
  → outputs: allocation · new_lots · failed · unrouted · run_tracker

Greedy, deterministic, equipment-day granularity. Capacity is a flat sheets/day per equipment; priority is a fixed rule; quantities flow 1:1.

그리디·결정론적·설비일 단위. 용량은 설비별 평면 시트/일, 우선순위는 고정 규칙, 수량은 1:1 흐름.
